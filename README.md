# Vue Shop

Тестовый проект интернет-магазина, созданный с использованием Vue 3, Pinia, Vue Router, TailwindCSS и mock-API на базе json-server.

## 🧾 Цель проекта

Цель — продемонстрировать архитектурный подход при работе с современным фронтенд-стеком. В проекте реализованы ключевые принципы построения масштабируемого SPA:

- Работа с глобальным состоянием через **Pinia**  
- Навигация с помощью **Vue Router**  
- Стилизация компонентов через **TailwindCSS**  
- Отделение логики работы с API в отдельный слой  
- Создание переиспользуемых UI-компонентов  
- Демонстрация composable-подхода и debounce  
- Структура с поддержкой layout'ов  

## 🚀 Установка и запуск проекта

### Установка зависимостей  
npm install

### Установка зависимостей  
npm run mock:server

Mock-сервер поднимается на http://localhost:3001 и использует файл db.json в корне проекта.

### Установка зависимостей  
npm run dev

Приложение будет доступно по адресу http://localhost:5173 (порт может отличаться).

### Архитектура проекта
- Vue 3 + Composition API — используется <script setup>.

- Pinia — глобальное хранилище. Получение данных реализовано через отдельный слой API (services/api), чтобы store не знал, откуда берутся данные.

- Vue Router — для маршрутизации между страницами.

- TailwindCSS — как основная система стилей. В приоритете — использование возможностей Tailwind, но добавлены и базовые переменные/настройки. Поскольку кастомных стилей немного, они собраны в одном файле.

- Базовые компоненты — реализованы как "прозрачные обёртки" (BaseInput, BaseSelect, BaseCheckbox). Это позволяет использовать v-bind="$attrs" и передавать стили и свойства напрямую из родителя.

- Поиск — вынесен в отдельный composable, где применяется lodash.debounce для оптимизации. Это демонстрация подхода к реактивной логике даже без реального запроса к API.

- Layout-система — внедрена структура layouts/, что позволяет масштабировать проект и использовать разные шаблоны страниц в будущем.

### Возможные улучшения
